# Cuadre

App para llevar ventas, gastos e inventario de dos negocios (restaurante y tienda online), con caja POS.
Funciona en el navegador y se instala en el celular como app.

## Probarla en tu computador

```bash
npm install
npm run dev
```

## Estado

Versión 1: Caja POS, Inicio, Movimientos (ventas y gastos) e Inventario con fotos.
Los datos se guardan por ahora en el navegador (`src/store.js`); el siguiente paso es conectarlos a Supabase.
